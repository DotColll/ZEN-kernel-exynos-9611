# ZEN-kernel-exynos-9611

ZEN Kernel

Custom Overclocking Kernel for Samsung Galaxy Tab S6 Lite (LTE)

ZEN Kernel is a custom Linux kernel project based on Samsung's officially released kernel source for the Samsung Galaxy Tab S6 Lite LTE (SM-P615), powered by the Exynos 9611 platform.

The project introduces custom kernel modifications, performance optimizations and overclocking-related enhancements.

Device Information

- Device: Samsung Galaxy Tab S6 Lite LTE
- Model: SM-P615
- SoC: Samsung Exynos 9611
- Architecture: ARM64
- Project: ZEN Kernel
- Release: V1

Features

- Custom CPU and GPU frequency configurations 2.4/1.82
- Performance optimizations
- Kernel-level modifications
- Custom tuning and enhancements

Refer to the official XDA thread for the complete feature list and release-specific details.
